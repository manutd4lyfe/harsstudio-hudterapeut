# Hårstudio & Hudterapeut Hemsida

En modern och responsiv hemsida för hårstudio och hudterapeut verksamheter.

## Filer
- `index.html` - Huvudfilen med allt innehåll
- `styles.css` - Styling och design
- `script.js` - Interaktivitet och animationer

## Användning
Öppna `index.html` i en webbläsare för att se hemsidan.
